# Contact Book Using Dictionaries

## Description
This project is a simple command-line contact book developed using Python dictionaries. It allows users to manage contact information easily.

## Objective
To understand Python dictionaries, key-value pairs, loops, functions, conditional statements, and CRUD operations.

## Features
- Add new contacts
- Search contacts by name or phone number
- Update existing contact details
- Delete contacts
- View all saved contacts
- Validate duplicate phone numbers
- Handle invalid menu choices

## Tools Used
- Python 3
- Visual Studio Code

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

   python3 contact_book.py

## Input
The program accepts a contact's name, phone number, email, and menu choice.

## Output
The program displays contact details and success or error messages based on the selected operation.

## Concepts Used
- Dictionaries
- Functions
- Loops
- Conditional statements
- User input
- CRUD operations

## Note
Contacts are stored in memory and will be lost when the program exits.
